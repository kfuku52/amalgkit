# TMM numeric references

`generate_tmm_fixtures.py` does not import AMALGKIT. It uses exact `Fraction`
count ratios/products for average ranks and 60-digit `Decimal` logarithms,
weights and geometric centering. The checked-in inputs cover sparse, fractional
and composition-biased counts, including the August 2026 audit cases with
trim-boundary ties (14, 29) and even-median reference instability (9, 15).

Regenerate the eight checked-in cases and the five non-boundary edgeR examples:

```bash
python tests/reference/generate_tmm_fixtures.py --edger
```

R and edgeR are needed only to regenerate `tmm-edger.json`, not to run tests.
`tmm_edger.R` uses a fixed first-column reference. The recorded package version
is part of the fixture provenance. No reference is generated by the production
Python TMM code. Extend the audit to all 40 deterministic synthetic matrices:

```bash
python tests/reference/generate_tmm_fixtures.py --all --output /tmp/tmm-all.json
```

Boundary cases intentionally use the exact-rank oracle rather than bitwise
agreement with a particular R math library. Logarithmic rounding can split
equal mathematical M/A values in edgeR. AMALGKIT instead ranks positive count
ratios/products before logs and chooses the first original sample among the two
central factors for an even median. Tests keep a strict `1e-12` tolerance.
